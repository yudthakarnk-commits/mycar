# MYCAR v3 — Upgrade Dashboard, Trip & TNG PDF Import

สำหรับ GitHub Pages `https://yudthakarnk-commits.github.io/mycar/`

## อัปเดตอะไรแล้ว

1. **Summary มีรูปรถทางขวา** — รุ่น Toyota Corolla Cross แสดงภาพอ้างอิงของรถรุ่นเดียวกันจาก Wikimedia Commons พร้อมเครดิตภาพ แตะที่รูปเพื่อค้นหารูปอ้างอิงรุ่นอื่นหรืออัปโหลดรูปของตัวเองได้ ภาพที่เลือกซิงค์ข้ามอุปกรณ์ผ่าน `mycar_records` (ไม่ต้องตั้งค่า Supabase Storage หรือสร้างตารางใหม่)
2. **แก้ RON95 เฉพาะรถทะเบียน VQG8991** — รายการเติมน้ำมันเก่าที่ระบุ `Petrol (grade unspecified)` จะเปลี่ยนเป็น `RON95` 24 รายการ พร้อมแก้ Default Fuel ของรถบนการโหลดข้อมูลครั้งแรกหลังอัปเดต ชื่อรถเดิม `Toyota Corolla Cross 2025` จะถูกแก้เป็น `Toyota Corolla Cross` เฉพาะกรณีที่ยังเป็นชื่อนั้น หากผู้ใช้แก้ชื่อไปแล้ว จะไม่เปลี่ยนซ้ำ
3. **Summary แยกเลขไมล์สองประเภท** — `Latest recorded odometer` (ค่าเลขไมล์บนมาตรวัดล่าสุดในช่วงที่เลือก) และ `Logged trips` (ผลรวมระยะทางการเดินทางที่บันทึก) แสดงทั้งคู่ ไม่เอาสองค่านี้มาปนกัน ตัวเลข 22,070 กม. เป็นเลขไมล์สะสม ไม่ใช่ระยะทางที่วิ่งเฉพาะปี 2026
4. **เพิ่ม Trip สะดวกขึ้น** — เมื่อสร้าง Trip ใหม่ ระบบใส่ Start Odometer ให้จาก End Odometer ของ Trip ก่อนหน้าตามวันของรายการที่กำลังกรอก; กรณีไม่มี Trip ก่อนหน้าจะปล่อยว่าง; ถ้ากรอกเองระบบจะไม่เขียนทับ; การแก้ไข Trip เดิมยังใช้ค่าที่บันทึกไว้
5. **นำเข้า Touch 'n Go PDF** — ไปที่แท็บ `Tax/Ins` → `Import Touch 'n Go PDF` → เลือกไฟล์ PDF → ใส่รหัสผ่าน PDF หากมี → `Read PDF & check duplicates` → ตรวจสอบรายการใหม่/ซ้ำ/ไม่รู้จัก → `Import new expenses` เพื่อบันทึกรายการใหม่เท่านั้น
6. **หัวแอปไม่กระตุกจากข้อความ Synced** — เปลี่ยนเป็นจุดคงขนาด: เขียว = ซิงค์แล้ว, เหลือง = กำลังซิงค์/รอส่ง, แดง = ซิงค์มีปัญหา, เทา = ออฟไลน์; แตะจุดเพื่อสั่งซิงค์ทันที รายละเอียดดูใน Settings

## สำคัญก่อนอัปเดต

- ที่ MYCAR เดิม เปิด `Settings` → `Export Backup (JSON)` และเก็บไฟล์สำรองไว้ก่อน
- **ไม่ต้องรัน SQL เพิ่ม**: โครงสร้าง Supabase `mycar_records` เดิมรองรับการเปลี่ยนแปลงทั้งหมด
- **ไม่ต้องอัปโหลด PDF หรือรหัสผ่านให้ GitHub หรือ Supabase**: ตัวอ่าน PDF ทำงานในเครื่องผู้ใช้ ไฟล์และรหัสผ่านไม่ถูกส่งไปเก็บที่เซิร์ฟเวอร์ (แต่รายการค่าใช้จ่ายที่กดยืนยันนำเข้าจะซิงค์ไปยัง Supabase เหมือนรายการอื่น)
- ตัวอ่าน PDF ใช้ Mozilla PDF.js รุ่น `5.4.624` ผ่าน CDN แบบตรึงรุ่น ครั้งแรกที่ใช้งานตัวนำเข้า PDF จึงต้องเชื่อมต่ออินเทอร์เน็ต
- PDF ต้องเป็น Touch 'n Go eWallet Transaction History **ที่มีชั้นข้อความอ่านได้** ไม่ใช่ PDF สแกนภาพ และครอบคลุมคำว่า RFID/Toll/Parking ตามรูปแบบที่ตรวจสอบ หากไฟล์รายเดือนเปลี่ยนรูปแบบจนอ่านไม่ได้ ระบบจะแจ้งว่าไม่รองรับและไม่บันทึกอัตโนมัติ

## วิธีอัปเดต GitHub Pages (Windows — แนะนำ GitHub Desktop)

1. ติดตั้ง GitHub Desktop จาก https://desktop.github.com/ และลงชื่อเข้า GitHub
2. `File → Clone repository` แล้วเลือก `yudthakarnk-commits/mycar` หรือป้อน `https://github.com/yudthakarnk-commits/mycar`
3. ดาวน์โหลด/แตก ZIP ของ v3 ที่ให้ในแชต แล้วเปิด **โฟลเดอร์ภายใน ZIP** ที่เห็น `index.html`, `app.js`, `assets`, `icons` และไฟล์อื่น ๆ
4. คัดลอกไฟล์/โฟลเดอร์ทั้งหมดจากโฟลเดอร์นั้นไปทับ **Root** ของโฟลเดอร์ Repository ที่ GitHub Desktop clone ไว้ (ต้องได้ `mycar/index.html`, ไม่ใช่ `mycar/MYCAR_Upgrade_V3/index.html`)
5. กลับไป GitHub Desktop → ตรวจ `Changes` → ใส่ Summary `MYCAR v3 dashboard, trips and PDF import` → คลิก `Commit to main` → `Push origin`
6. ในเว็บ GitHub เข้า `Actions` และตรวจ `pages build and deployment` เป็นสีเขียว
7. ปิด MYCAR บนมือถือแล้วเปิดอีกครั้ง หากยังเห็นหน้าจอเดิม ให้เปิดลิงก์เว็บใน Chrome และรีเฟรช จากนั้นเปิดแอปที่ติดตั้งไว้ใหม่ ระบบ Service Worker v6 จะอัปเดตไฟล์ใหม่

## การตรวจสอบข้อมูลหลังอัปเดต

- ล็อกอินด้วยบัญชีเดิมและรอจุดสถานะสีเขียว
- เลือกรถทะเบียน `VQG8991` และปี `2026`, `All Months`
  - `Total Expenses` = **RM3,964.70**
  - `Latest recorded odometer` = **22,070 กม.**
  - `Logged trips` = **11,297 กม.** (ผลรวม 102 Trip ที่บันทึกช่วงมิถุนายน–พฤศจิกายน)
  - Fuel = **24 รายการ RM3,207.53** และแสดง `RON95`
  - Tax/Ins/Tolls = **123 รายการ RM757.17**
- เมื่อเลือก `October 2026`: ค่าใช้จ่ายรวม **RM843.71**, Fuel **RM665.02**, Toll **RM178.69**, Latest recorded odometer **21,618 กม.**
- ทดลองเพิ่ม Trip ใหม่ ระบบควรดึง End Odometer จาก Trip ก่อนหน้าให้อัตโนมัติ กรณีบันทึกย้อนหลังเลือกวันที่ให้ตรงก่อนตรวจเลขไมล์เริ่มต้น
- ทดลองอัปโหลด PDF ตุลาคม 2026 จากไฟล์ที่แนบก่อนหน้า โดยกรอกรหัส PDF ด้วยตัวเอง ผลลัพธ์ควรเป็น **28 รายการซ้ำ / 0 รายการใหม่ / RM0 ที่ต้องนำเข้า** และปุ่ม Import จะถูกปิด
- ทดลองแตะพื้นที่รูปรถบน Summary และเลือกภาพหรืออัปโหลดรูปใหม่ รอจุดสีเขียว แล้วเปิดอุปกรณ์อื่นเพื่อตรวจว่าภาพซิงค์

## ข้อจำกัดด้านข้อมูล

- บันทึกจาก PDF เป็นธุรกรรม `Toll` ในตาราง `tax` และ `Parking` ใน `other` ของรถที่เลือก **เฉพาะเมื่อผู้ใช้กด Import หลังดูตัวอย่าง**
- ระบบเทียบข้อมูลเก่าด้วยกลุ่ม `(รถ, วันที่, ประเภท, จำนวนเงิน)` และลำดับการเกิดซ้ำ เพื่อป้องกันการลงซ้ำหลายรายการราคาท่ากันในวันเดียวกัน; ถ้าข้อมูลเดิมไม่มีเลขอ้างอิงธุรกรรม อาจมีกรณีตรวจซ้ำไม่แน่นอนได้ จึงต้องดูตารางตัวอย่างก่อนยืนยัน
- PDF จะไม่เติมรายการรับเงิน/Top Up/Transfer ที่ไม่ใช่ Toll หรือ Parking; ระบบจะจัดเป็นรายการไม่รู้จักและไม่บันทึก
- ภาพรถอัตโนมัติเป็น **ภาพอ้างอิงรุ่นเดียวกัน** อาจต่างสี รุ่นย่อย หรือโฉมของรถผู้ใช้ ภาพค้นหาจาก Wikimedia Commons ที่มีสัญญาอนุญาตใช้ซ้ำ และแสดงเครดิตต้นทาง
- รูปที่อัปโหลดถูกย่อและบีบอัดเก็บใน payload ของรถ ทำให้ซิงค์ข้ามอุปกรณ์ได้โดยไม่ต้องสร้าง Storage bucket เหมาะกับการเก็บภาพจำนวนไม่มาก

## ผลทดสอบก่อนส่งมอบ

- ผ่าน JS syntax checks และ PWA package checks
- ผ่าน Playwright mobile viewport 390×844 กับ Supabase API จำลอง: โหลด 250 ระเบียน, รักษายอดเดิม, ย้าย RON95, แสดงรูป, คำนวณเลขไมล์, เติมเลขไมล์ Trip, ป้องกันการเขียนทับที่ผู้ใช้แก้เอง, ซิงค์/แสดงจุดสถานะแบบไม่เปลี่ยนขนาด
- ใช้ข้อมูล PDF ที่แนบจริง (แบบสกัดข้อความพร้อมพิกัดจาก PDF 4 หน้า) ทดสอบตัวแยกรายการ อ่านได้ **28 รายการ RM178.69** และตรวจเป็นรายการซ้ำครบ 28 รายการ; ทดสอบกล่องอัปโหลด PDF ผ่านชั้นอ่าน PDF จำลองแล้ว
- ยัง **ไม่ได้ทดสอบการดาวน์โหลด PDF.js ผ่าน CDN และการถอดรหัส PDF ผ่าน PDF.js จริงในเบราว์เซอร์ที่มีเครือข่าย** เนื่องจากเครื่องทดสอบไม่มีอินเทอร์เน็ต และยังไม่ได้แก้ข้อมูลผู้ใช้ใน Supabase จริงจากเครื่องทดสอบ

## MYCAR v3.1 — รูปรถและการอัปเดตมือถือ
- หน้า Summary เปลี่ยนรูป Corolla Cross ที่เป็นภาพเต็มพร้อมฉากหลัง ให้เป็นภาพประกอบ 3/4 พื้นหลังโปร่งใสทางขวาของยอดเงิน (ภาพประกอบ ไม่ใช่ภาพยืนยันสีหรือรุ่นย่อยของรถจริง)
- ผู้ใช้ยังเลือกภาพอื่นหรืออัปโหลดเองได้ตามเดิม; ภาพจาก Wikimedia จะมีข้อความเครดิตขนาดเล็ก
- Service Worker ตรวจเวอร์ชันใหม่เมื่อเข้าเว็บและเมื่อกลับมาหน้าแอป พร้อมโหลดไฟล์ล่าสุดเมื่อออนไลน์ และเก็บเวอร์ชันแคชไว้ใช้ตอนออฟไลน์
- อัปโหลดไฟล์ทั้งหมดจาก ZIP ไปยัง GitHub ใน repository `mycar` (เลือกแทนที่ไฟล์ชื่อเดิม) ไม่มีการแก้ไข Supabase, ไม่ต้องรัน SQL
- หาก PWA ยังแสดงหน้าเก่าหลัง GitHub Pages Deploy ให้เปิดผ่าน Chrome URL `https://yudthakarnk-commits.github.io/mycar/?v=3.1.0` หนึ่งครั้งแล้วเปิดจากไอคอนอีกครั้ง การ logout/login ไม่เกี่ยวกับการรีเฟรชโค้ด
- ก่อนอัปเดตแนะนำ Export Backup (JSON) เพื่อสำรองข้อมูลส่วนตัว
